# Календарь

Встроенный WASM-плагин, включён по умолчанию. Исходник — [apps/calendar](../../apps/calendar/src/lib.rs).

## Как устроено

- **Календари и события** лежат в AppData пользователя: `.appdata/calendar/calendars/<id>/` —
  `calendar.json` (название и цвет) и по файлу `.ics` на событие вместе с его изменёнными
  повторами. Индекс для страницы — `.appdata/calendar/index/<id>.json`, пересчитывается по etag;
  удалить его безопасно.
- **Первый календарь** «Calendar» появляется сам. Последний свой календарь удалить нельзя.
- **Страница** — месяц, календари с цветами (скрыть — флажок), форма события: название, весь день,
  начало и конец, повтор (день, неделя, месяц, год), место, заметки. Время показывается в часовом
  поясе браузера, новые события пишутся с `TZID` этого пояса.
- **Повторы** считаются по `RRULE` с учётом `EXDATE` и перенесённых повторов (`RECURRENCE-ID`).
  Правка на странице меняет всю серию. Правило, которое страница не умеет показать (например,
  «по понедельникам и средам»), сохраняется как есть.
- **Правка сохраняет чужое.** Страница меняет только свои поля; напоминания, участники и прочее,
  что добавил другой клиент, остаются. Если файл изменили после открытия формы — `409`, ничего
  не перезаписывается.

## Общие календари

Своим календарём можно поделиться с другими пользователями: в окне календаря — «Поделиться…»,
дальше логин и права — «просмотр» или «правка» ([общий доступ](../api/app-shares.md)).

- Получатель видит календарь в своём списке с подписью «от …» и на телефоне — с именем владельца
  в скобках. С «просмотром» события открываются только для чтения, CalDAV-клиенту приходит
  `current-user-privilege-set` только с `read`, запись — `403`.
- Название и цвет меняет только владелец.
- Получатель может убрать календарь у себя: «Убрать из моих календарей» на странице или удаление
  на телефоне. У владельца он остаётся.
- Владелец видит и закрывает доступы в окне «Поделиться…» и в «Настройки → Общий доступ к данным
  приложений». Удалённый календарь пропадает у всех.

В адресах общий календарь — `shared-<id доступа>`; события лежат у владельца.

## Подключить телефон или программу

CalDAV-клиенты (iPhone, macOS, [DAVx⁵](https://www.davx5.com/) на Android, Thunderbird) входят
по [паролю приложения](../api/app-passwords.md) с доступом к «Календарю»:

| Поле     | Значение                                                                 |
|----------|--------------------------------------------------------------------------|
| Сервер   | адрес облака, например `https://cloud.example.com`                       |
| Логин    | ваш логин                                                                |
| Пароль   | пароль приложения, не пароль от аккаунта                                 |

Клиент находит календари сам через `/.well-known/caldav` → `/app/calendar/dav/`. Если просит полный
адрес — `https://cloud.example.com/app/calendar/dav/`. Те же данные показывает кнопка
«Подключить устройство» на странице календаря. Пароль только на чтение даёт смотреть календари,
но не менять.

## CalDAV

Код — [dav.rs](../../apps/calendar/src/dav.rs).

| Путь                                       | Что это                     |
|--------------------------------------------|-----------------------------|
| `/app/calendar/dav/`                       | начало: кто вошёл           |
| `/app/calendar/dav/principal/`             | пользователь                |
| `/app/calendar/dav/calendars/`             | его календари               |
| `/app/calendar/dav/calendars/<id>/`        | календарь                   |
| `/app/calendar/dav/calendars/<id>/<name>`  | событие `.ics`              |

- Методы: `OPTIONS`, `PROPFIND` (`Depth` 0 и 1), `PROPPATCH` (название, цвет), `REPORT`
  (`calendar-multiget`, `calendar-query` с `time-range`), `MKCALENDAR`, `GET`, `PUT`, `DELETE`
  с `If-Match` / `If-None-Match`.
- Синхронизация — по `getctag` и etag файлов. `sync-collection` пока нет — клиенты обходятся без него.
- Хранятся только события (`VEVENT`); задачи (`VTODO`) календарь не принимает.

## Пока нет

Подписки на чужие `.ics`, правка одного повтора серии со страницы,
напоминания на странице — см. [ROADMAP](../../ROADMAP.md#плагины).
