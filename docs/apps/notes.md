# Заметки

Встроенный WASM-плагин, включён по умолчанию. Исходник — [apps/notes](../../apps/notes/src/lib.rs).

## Как устроено

- **Папка.** При первом открытии «Заметки» просят папку — создать «Notes» (или «Заметки») или выбрать
  свою ([запрос доступа](../dev/plugins.md#файлы-пользователя)). Доступ отзывается в «Настройки →
  Приложения с доступом».
- **Заметка = `.md`-файл** в этой папке или её подпапках (до 4 уровней). Подпапки — группы в списке.
  Файлы можно открывать, скачивать и править где угодно — список подхватит изменения.
- **Заголовок** — первая непустая строка без `#`, иначе имя файла.
- **Сохранение** — автоматически, через ~1 с после ввода. Если файл изменили в другом месте, заметка
  не перезаписывается: показывается предупреждение и кнопка «Обновить».
- **Поиск** — по заголовку и тексту (первые 64 КБ заметки).
- **Просмотр** — Markdown с таблицами, зачёркиванием и списками задач. HTML в заметке показывается
  как текст, `javascript:`-ссылки отключены.
- **Индекс** — `.appdata/notes/index.json`: заголовки и текст для списка и поиска. Пересчитывается только
  для изменившихся файлов; удалить его безопасно — он соберётся заново.

## API плагина

Под `/app/notes/api/` — для страницы плагина; таблица — в начале [lib.rs](../../apps/notes/src/lib.rs).
