# Текстовый редактор

Встроенный WASM-плагин, включён по умолчанию — устроен как [Заметки](notes.md), но без своей папки
и без пункта в боковой панели. Исходник — [apps/editor](../../apps/editor/src/lib.rs).

## Как открыть

В меню любого текстового файла — «Редактировать как текст» (а файл без своего просмотра
открывается в нём и двойным щелчком). Подходят:

- файлы типов `text/*`, JSON, XML, JavaScript, YAML, TOML, SQL, shell;
- и по расширению, каким бы ни был тип: `.env`, `.ini`, `.conf`, `.ts`, `Dockerfile`, `Makefile`,
  `.gitignore` и [другие](../../apps/editor/manifest.toml) (`extensions` в
  [`[[open_with]]`](../dev/plugins.md#открыть-с-помощью)).

Редактор получает доступ только к открытому файлу и только пока открыта его страница
([как это устроено](../dev/plugins.md#открыть-с-помощью)). Файлы из «Доступных мне» с правом
изменять тоже редактируются.

## Что умеет

- **Подсветка синтаксиса** — своя, без внешних библиотек ([ui/highlight.js](../../apps/editor/ui/highlight.js)):
  JavaScript/TypeScript, Rust, Go, Java/Kotlin, C/C++, C#, Swift, PHP, Dart, Python, Ruby, Lua, shell,
  PowerShell, SQL, JSON, YAML, TOML/INI, `.env`, HTML/XML, CSS, Markdown, Dockerfile, Makefile, diff.
  Язык — по имени и типу файла, его можно сменить в списке. Файлы больше 512 КБ — без подсветки.
- **Markdown** — «Текст», «Рядом» и «Просмотр» (таблицы, списки задач; HTML показывается текстом,
  картинки с других сайтов — по кнопке, как в Заметках).
- **Сохранение** — через секунду после ввода и сразу по Ctrl+S. Сохраняется только поверх той
  версии, что была прочитана: если файл тем временем сохранили в другом месте, редактор спрашивает —
  записать свой текст поверх или загрузить чужую версию. Прежнее содержимое остаётся в
  [версиях](../api/files.md#версии).
- **Как было в файле** — окончания строк (CRLF или LF) и BOM сохраняются.
- Номера строк, перенос длинных строк (запоминается), Tab — отступом, который принят в файле.
- Только UTF-8: другой файл не открывается (`415`), чтобы не сохранить его испорченным.
  Размер — до [предела данных](../dev/plugins.md#лимиты) плагина (16 МБ при ×1).

## API плагина

| Запрос | Что делает |
|---|---|
| `GET /app/editor/edit?file=<id>` | страница редактора |
| `GET /app/editor/api/file?id=` | `{id, name, mime_type, size, etag, content}` |
| `PUT /app/editor/api/file?id=` | `{content, etag}` → `{etag, size}`; `409`, если файл изменился |
| `POST /app/editor/api/preview` | Markdown (тело) → `{html, blocked_images}` |
