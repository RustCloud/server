# Коды ошибок

Формат: `{"error": {"code": "…", "message": "…"}}`. HTTP-статус задаёт `ErrorKind`
([error.rs](../../crates/core/src/error.rs)).

## 400 Bad Request

| Код                    | Когда                                                   |
|------------------------|---------------------------------------------------------|
| `INVALID_NAME`         | недопустимое имя файла или папки                        |
| `INVALID_USERNAME`     | недопустимое имя пользователя                           |
| `INVALID_DISPLAY_NAME` | недопустимое отображаемое имя                           |
| `INVALID_EMAIL`        | неверный email                                          |
| `INVALID_QUOTA`        | отрицательная квота                                     |
| `INVALID_EXPIRY`       | срок ссылки в прошлом                                   |
| `INVALID_SETTINGS`     | значение настройки не прошло проверку                   |
| `INVALID_SCOPES`       | у пароля приложения нет приложений или одно дважды      |
| `INVALID_PLUGIN`       | архив плагина не подходит — причина в `message`         |
| `TOO_MANY_APP_PASSWORDS` | больше 50 паролей приложений                          |
| `WEAK_PASSWORD`        | пароль слишком простой                                  |
| `WRONG_PASSWORD`       | неверный текущий пароль при смене                       |
| `UNKNOWN_PROVIDER`     | нет такого способа входа                                |
| `CANNOT_CHANGE_SELF`   | администратор отключает или понижает себя               |
| `ROOT_FOLDER`          | действие недоступно для корневой папки                  |
| `NOT_A_FILE`           | у папки нет содержимого для скачивания                  |
| `NOT_A_FOLDER`         | ожидалась папка                                         |
| `MOVE_INTO_ITSELF`     | перемещение папки в саму себя или вложенную             |
| `COPY_INTO_ITSELF`     | то же для копирования                                   |
| `CROSS_OWNER_MOVE`     | перемещение между пользователями                        |
| `IN_TRASH`             | в корзину можно только удалить, не положить              |
| `NOT_IN_TRASH`         | восстановить можно только то, что лежит в корзине само   |
| `TRASH_FOLDER`         | саму корзину нельзя переименовать, переместить, удалить  |
| `HOST_NOT_ALLOWED`     | адрес не разрешён ([`only_listed_urls`](../configuration.md#server)) |

## 401 Unauthorized

| Код                   | Когда                                    |
|-----------------------|------------------------------------------|
| `UNAUTHORIZED`        | нет сессии или она истекла               |
| `INVALID_CREDENTIALS` | неверные имя или пароль                  |

Неверный [пароль приложения](app-passwords.md) — `401 UNAUTHORIZED` с `WWW-Authenticate: Basic`.

## 403 Forbidden

| Код                   | Когда                                                 |
|-----------------------|-------------------------------------------------------|
| `FORBIDDEN`           | нужны права администратора                            |
| `CSRF_CHECK_FAILED`   | нет `X-Requested-With` ([CSRF](README.md#csrf))       |
| `REGISTRATION_CLOSED` | регистрация закрыта                                   |
| `ACCOUNT_DISABLED`    | аккаунт отключён                                      |
| `PERMISSION_NOT_DECLARED` | приложение не объявило такой доступ в манифесте   |
| `APP_PASSWORD_SCOPE`  | пароль приложения не открывает это приложение         |
| `PLUGIN_REQUIRED`     | плагин — часть сервера, его не отключить              |
| `PLUGIN_NOT_REMOVABLE` | плагин поставляется с сервером — его отключают, а не удаляют |
| `READ_ONLY`           | доступ только на чтение (пароль приложения, доступ плагина, общая папка) |

## 404 Not Found

`FILE_NOT_FOUND`, `VERSION_NOT_FOUND`, `USER_NOT_FOUND`, `SHARE_NOT_FOUND` (в т.ч. истёкшая ссылка и закрытый
[общий доступ](app-shares.md)),
`SETTINGS_NOT_FOUND`, `APP_NOT_FOUND` (в т.ч. отключённый плагин), `PLUGIN_NOT_FOUND`, `GRANT_NOT_FOUND` (в т.ч. закончившаяся сессия), `APP_PASSWORD_NOT_FOUND`,
`NOT_FOUND` (нет такого API-маршрута).

## 409 Conflict

| Код                | Когда                                              |
|--------------------|----------------------------------------------------|
| `NAME_TAKEN`       | в папке уже есть элемент с таким именем            |
| `ALREADY_EXISTS`   | то же, обнаружено базой при одновременных запросах |
| `USERNAME_TAKEN`   | имя пользователя занято                            |
| `FILE_LOCKED`      | файл редактируется в приложении, которое держит [блокировку](files.md#блокировки) |
| `FILE_CHANGED`     | файл изменился после чтения (`If-Match`, `write-if-match`) |
| `NOT_ENOUGH_SPACE` | мало места для теста скорости                      |
| `CONFIG_FILE_INVALID` | файл настроек испорчен — исправьте его вручную  |
| `PLUGIN_CANT_RUN`  | плагин не загрузился или его адрес занят другим    |
| `PLUGIN_EXISTS`    | плагин с таким `id` поставляется с сервером        |

## Прочие

| Статус | Код                 | Когда                                              |
|--------|---------------------|----------------------------------------------------|
| 413    | `FILE_TOO_LARGE`    | больше [`files.max_upload_mib`](../configuration.md#files) |
| 413    | `QUOTA_EXCEEDED`    | не помещается в квоту                              |
| 416    | —                   | `Range` вне файла (без JSON-тела)                  |
| 429    | `TOO_MANY_ATTEMPTS` | слишком много неудачных входов                     |
| 500    | `APP_FAILED`        | плагин упал, превысил память или время             |
| 500    | `INTERNAL`          | ошибка сервера; подробности — в [журнале](../admin.md#журнал) |
