# Доступ приложений к файлам

Доступ к файлам приложениям (плагинам) даёт только владелец файлов — администратор этого не может.
Правила — [files/src/grants.rs](../../crates/files/src/grants.rs), маршруты —
[server/src/grants.rs](../../crates/server/src/grants.rs). В интерфейсе — «Настройки → Приложения
с доступом».

## Виды доступа

| `kind`     | Что открывает             | Когда заканчивается                                           |
|------------|---------------------------|---------------------------------------------------------------|
| `session`  | один файл                 | приложение закрыто (`DELETE`), 2 мин без `keep-alive` или 12 ч |
| `standing` | папку и всё внутри неё    | пользователь отозвал (`DELETE`)                               |

Доступ к корневой папке — это все файлы пользователя. Клиент, который показывает открытый файл,
вызывает `keep-alive` раз в 30 секунд.

## Потолок — манифест

Приложение получает не больше, чем объявило в [манифесте](apps.md) (`permissions`), и не больше, чем
может сам пользователь:

| `permissions.files` | Можно выдать                               |
|---------------------|--------------------------------------------|
| `none`              | ничего                                     |
| `opened`            | `session` на файл                          |
| `folder`            | и `standing` на папку (кроме корня)        |
| `all`               | и `standing` на корневую папку             |

Запись (`write: true`) — только если объявлено `files_write = true`.

## Объект `Grant`

```json
{
  "id": "…", "app_id": "notes", "node": {…}, "write": true,
  "kind": "standing", "created_at": "…", "last_seen_at": "…"
}
```

`node` — [`Node`](files.md#объект-node).

## Запросы

| Запрос                                   | Тело                                   | Ответ        |
|------------------------------------------|----------------------------------------|--------------|
| `GET /api/v1/grants`                     | —                                      | `[Grant]` — действующие, новые первыми |
| `POST /api/v1/grants`                    | `{app_id, node_id, write?, kind}`      | `201 Grant`  |
| `POST /api/v1/grants/{id}/keep-alive`    | —                                      | `204`, только `session` |
| `DELETE /api/v1/grants/{id}`             | —                                      | `204`        |
| `DELETE /api/v1/grants/{id}?closing=true` | —                                     | `204` — страницу с файлом закрыли: `session` живёт ещё минуту, чтобы редактор, с которым работает приложение, успел сохранить; [токены](../dev/plugins.md#токены-для-других-серверов) приложения продлевают её, пока им пользуются |

Ошибки: `404 APP_NOT_FOUND`, `403 PERMISSION_NOT_DECLARED`, `404 FILE_NOT_FOUND`,
`404 GRANT_NOT_FOUND` (в т.ч. закончившаяся сессия). Выдача и отзыв попадают в
[журнал](../admin.md#журнал) (`grant.create`, `grant.revoke`).
Пока файл или папка в [корзине](files.md#корзина), доступ к ним приостановлен; удаление навсегда
удаляет и доступ.
