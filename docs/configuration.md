# Настройки

Один TOML-файл: `--config <путь>` или `RUSTCLOUD_CONFIG`, по умолчанию `rustcloud.toml`
(в Docker — `/data/rustcloud.toml`). Пример со всеми параметрами —
[rustcloud.example.toml](../rustcloud.example.toml).

Файла может не быть: действуют значения по умолчанию, а первое сохранение в UI его создаст.

## Откуда берутся значения

По убыванию приоритета:

1. **Переменные окружения** — `RUSTCLOUD_<КЛЮЧ>` для ключей верхнего уровня,
   `RUSTCLOUD_<ТАБЛИЦА>__<КЛЮЧ>` для таблиц: `RUSTCLOUD_SERVER__PUBLIC_URL`.
   В UI такие параметры видны, но заблокированы.
2. **Файл**.
3. **Значения по умолчанию**.

## Когда применяются

- **Ключи верхнего уровня** — только при запуске.
- **Таблицы** — сразу после сохранения в [Администрировании](admin.md#настройки) или
  [`PUT /api/v1/admin/settings/{section}`](api/admin.md#настройки). Сохраняются только изменённые
  ключи, комментарии в файле остаются ([settings_file.rs](../crates/server/src/settings_file.rs)).

Если после изменения в UI доступ пропал (например, `only_listed_urls`) — исправьте файл и
перезапустите сервер.

## Верхний уровень

| Ключ           | По умолчанию                          | Что задаёт                         |
|----------------|---------------------------------------|------------------------------------|
| `listen`       | `0.0.0.0:8080`                        | адрес и порт                       |
| `database_url` | `sqlite://data/rustcloud.db?mode=rwc` | SQLite или `postgres://…`          |
| `data_dir`     | `data`                                | где лежат файлы и `apps/` — [плагины](dev/plugins.md#установка) |
| `log`          | `info`                                | уровень логов; `RUST_LOG` важнее   |
| `builtin_apps_dir` | не задан (в Docker — `/usr/share/rustcloud/apps`) | встроенные [плагины](dev/plugins.md#установка) |
| `media_tools_dir` | не задан (в Docker — `/usr/libexec/rustcloud`) | статические ffmpeg и ffprobe для [`use.ffmpeg`](dev/use.md); без них возможность недоступна |

Код: [config.rs](../crates/server/src/config.rs).

## `[server]`

| Ключ               | По умолчанию | Что задаёт                                                         |
|--------------------|--------------|--------------------------------------------------------------------|
| `public_url`       | пусто        | адрес для пользователей и ссылок; `https://` включает `Secure`-cookie и HSTS |
| `other_urls`       | `[]`         | другие адреса сервера (например, в LAN)                            |
| `only_listed_urls` | `false`      | отвечать только на `public_url`, `other_urls` и `localhost`        |
| `cors_origins`     | `[]`         | сайты, которым разрешено обращаться к API из браузера              |
| `trusted_proxies`  | `[]`         | прокси, чьим `X-Forwarded-For` / `-Proto` можно верить             |

Код: [network.rs](../crates/server/src/network.rs). См. [За reverse proxy](install.md#за-reverse-proxy).

## `[files]`

| Ключ             | По умолчанию | Что задаёт                       |
|------------------|--------------|----------------------------------|
| `max_upload_mib` | без лимита   | максимальный размер одного файла |
| `trash_days`     | `30`         | сколько дней удалённое лежит в корзине; `0` — пока не удалят вручную |
| `versions_keep`  | `10`         | сколько последних [версий](api/files.md#версии) файла хранить в любом случае |
| `versions_days`  | `30`         | версии за столько дней тоже хранятся, сколько бы их ни было; оба `0` — версий нет |

Код: [files/src/settings.rs](../crates/files/src/settings.rs).

## `[plugins]`

Что могут все [плагины](admin.md#плагины) вместе. Лимиты каждого плагина — три множителя: из его
манифеста или из «Расширенных настроек» на вкладке «Плагины»
([Лимиты](dev/plugins.md#лимиты)).

| Ключ         | По умолчанию | Что задаёт                                              |
|--------------|--------------|---------------------------------------------------------|
| `workers`    | `0`          | сколько порций [фоновых задач](dev/plugins.md#фоновые-задачи) плагинов выполняется одновременно на всём сервере, 0–64; `0` — половина ядер процессора. Применяется после перезапуска |
| `max_memory` | `16`         | больше памяти не получит ни один плагин: множитель 64 МиБ (1, 2, 4, 8, 16, 32, 64), при 16 — 1 ГиБ |
| `proxy_connections` | `256` | WebSocket-соединений с [сервисами плагинов](dev/plugins.md#сервис-через-адрес-облака) одновременно на всём сервере |
| `proxy_connections_per_user` | `8` | то же на одного пользователя; открытый документ занимает одно |
| `proxy_requests_per_user` | `16` | остальных запросов к сервисам одновременно от одного пользователя; лишние — `429` |
| `proxy_body_mib` | `256` | наибольшее тело запроса к сервису, МиБ (`413`) |

Ключи `memory_mib` и `time_seconds` прежних версий читаются и не действуют.
Код: [plugins.rs](../crates/server/src/plugins.rs).

## `[media]`

[`use.ffmpeg`](dev/use.md) — ffmpeg, который сервер запускает для плагинов, в песочнице.

| Ключ             | По умолчанию | Что задаёт                                                          |
|------------------|--------------|---------------------------------------------------------------------|
| `enabled`        | `true`       | плагины, которым админ утвердил `use.ffmpeg`, могут им пользоваться |
| `workers`        | `0`          | процессов ffmpeg одновременно, 0–64; `0` — половина ядер. После перезапуска |
| `memory_mib`     | `1024`       | память одного процесса, 64–16384 МиБ                                |
| `time_seconds`   | `30`         | время одной операции, 1–600 с                                       |
| `max_megapixels` | `200`        | фото и кадры видео больше — отклоняются до начала работы             |

Нужен `media_tools_dir` со статическими ffmpeg и ffprobe ([docker/build-ffmpeg.sh](../docker/build-ffmpeg.sh)):
динамический ffmpeg в песочнице не запустится — она не даёт открыть его библиотеки.

## `[onnx]`

[`use.onnx`](dev/use.md#use-onnx) — нейросети, которые сервер запускает для плагинов, каждую модель в
своём процессе в песочнице.

| Ключ                  | По умолчанию | Что задаёт                                                     |
|-----------------------|--------------|----------------------------------------------------------------|
| `enabled`             | `true`       | плагины, которым админ утвердил `use.onnx`, могут им пользоваться. После перезапуска |
| `workers`             | `4`          | моделей, загруженных одновременно (процессов), 1–64             |
| `memory_mib`          | `2048`       | память процесса одной модели, 128–65536 МиБ                     |
| `time_seconds`        | `60`         | время одного вызова или загрузки модели, 1–600 с                |
| `keep_loaded_seconds` | `300`        | сколько модель остаётся в памяти после последнего вызова, 0–86400 с; `0` — выгружать сразу |
| `max_model_mib`       | `1024`       | самый большой файл модели; меньше `memory_mib`                  |

Код: [crates/ml](../crates/ml/src/lib.rs).
