# Хранилище (`BlobStore`)

Трейт — [core/src/blob.rs](../../crates/core/src/blob.rs). Реализация для диска —
[storage-local](../../crates/storage-local/src/lib.rs).

Имена, папки и владельцы лежат в базе (`nodes`). Хранилище видит только непрозрачные
**блобы по ключу**: ключ — свежий UUID на каждую версию файла, поэтому хранилищу не нужно знать
о путях и пользователях.

## Методы

| Метод                        | Обязателен | Что делает                                                  |
|------------------------------|:----------:|-------------------------------------------------------------|
| `put(key, stream) -> u64`    | да         | записать новый блоб; при обрыве потока — удалить частичный  |
| `get(key, range)`            | да         | поток байт, весь блоб или `ByteRange` (уже проверен)        |
| `delete(key)`                | да         | удалить; отсутствующий блоб — не ошибка                     |
| `copy(from, to)`             | да         | скопировать в новый ключ                                    |
| `describe() -> StorageInfo`  | да         | `kind` и `location` для [страницы хранилища](../admin.md#хранилище) |
| `capacity()`                 | нет        | всего/свободно; по умолчанию `None` (S3)                    |
| `forget_cached(key)`         | нет        | сбросить кэш ОС перед тестом чтения                         |
| `speed_test(bytes)`          | нет        | готовая реализация через `put`/`get`/`delete`               |

## Правила

- Ключ — короткая ASCII-строка без `/`. Всё остальное отклоняйте: ключ не должен выходить за
  пределы хранилища.
- Блоб либо целиком, либо отсутствует. `storage-local` пишет в `tmp/` и атомарно
  переименовывает в `blobs/`.
- Потоки, а не буферы: размер файла не должен зависеть от памяти.

## Подключение

Сейчас выбор жёсткий — `AppState::open` в [server/src/lib.rs](../../crates/server/src/lib.rs):

```rust
let blobs = LocalBlobStore::open(config.startup.data_dir.join("files")).await?;
```

Для S3: новый крейт `storage-s3` с `impl BlobStore`, ключ конфигурации для выбора и ветка здесь.
Тест скорости и страница хранилища заработают сами, без объёма диска.
